description: Import notes from JSONL format
argument-hint: <file> [--path] [--overwrite]
---

Import notes from a JSONL file (as generated by `/obsidian:export`).

- $1: Path to the JSONL file (required)
- `--path`: Prefix all note paths with this folder
- `--overwrite`: Overwrite existing notes (default: skip)

If the file path is missing, ask the user for it.

## JSONL format expected

Each line is a JSON object with at minimum `path` and `content`:
```json
{"path": "folder/note.md", "properties": {"type": "project", "status": "open", "priority": 2}, "tags": ["backend"], "content": "# Title\n..."}
```

## Import steps

For each line in the JSONL file:
1. Parse the JSON object
2. If `--path` given, prepend it to the note path
3. Check if a note already exists at that path
4. If it exists and `--overwrite` is not set, skip and log
5. If it does not exist or `--overwrite` is set:
   a. Call `create_note` with path, content, and overwrite flag
   b. For each property in `properties`, call `set_property` with the correct type:
      - type, status, assignee -> text
      - priority -> number
      - tags -> list
      - created, updated -> datetime
      - compacted -> checkbox
   c. Log success
